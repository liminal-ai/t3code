# Provider Event-Stream Fidelity Probe

Date: 2026-07-07

## Tap-Point Recommendation

Codex: consume `item.completed` as the primary capture tap. For this probe, completed user, assistant, and command items carried the full normalized content needed for capture, including `payload.data.item.aggregatedOutput` for the 108,894-byte `seq 1 20000` output. Deltas are useful for live UI but are not required to reconstruct final content in this run. Evidence: `packages/lhc-host/test/fixtures/event-fidelity/codex/codex-normalized.jsonl` lines 7, 9, and 19; size summary in `codex-normalized-summary.json` lines 31-42.

Claude: do not rely on `item.completed` alone as a universal capture source. Assistant text is self-contained in `payload.detail`, but normal user prompts did not appear as `item.completed` user-message items; large command output is lossy in `payload.data.result.content`, `content.delta`, and inline `raw`. Patch `apps/server/src/provider/Layers/ClaudeAdapter.ts` in `handleUserMessage` where `toolData` is built: when `raw.payload.tool_use_result.persistedOutputPath`/`persistedOutputSize` is present, read or otherwise surface the full persisted output into a durable normalized field such as `payload.data.result.fullOutput` plus size/path metadata. Also patch Claude reasoning mapping if reasoning capture matters: this run's rollout has a `thinking` block, but the normalized stream emitted no reasoning item/delta. Evidence: `claude-normalized.jsonl` lines 12-14 and `claude-rollout-excerpt.jsonl` lines 8-10; sidecar proof in `claude-tool-result-sidecar-excerpt.txt` lines 1-41.

## Method

I added scratch probe scripts under `packages/lhc-host/probes/`. They are outside `packages/lhc-host/src`, and `packages/lhc-host/tsconfig.json` includes only `src`, so they are not part of normal package typecheck/test globs.

Each provider ran in a fresh temp git repo with three turns: large command output (`seq 1 20000`), a small file edit, and an interrupted/failed slow-turn probe. Fixture files are trimmed under `packages/lhc-host/test/fixtures/event-fidelity/{claude,codex}/`; summaries preserve original byte counts and source line numbers.

## Deviations

The direct adapter harness worked, so I did not use the dev-server NDJSON fallback. Claude's interrupted turn produced `state: failed` with an interruption diagnostic rather than `state: interrupted`; the rollout separately recorded `[Request interrupted by user]`. The Claude harness process lingered after writing `finishedAt`; I interrupted the probe after all fixture files and turn completions were flushed.

MCP tool calls and true Codex `file_change` items were not observed in these cheap sessions. Codex chose command execution for the file-edit prompt.
